🚀 GitSpot

A sleek Flutter app to explore GitHub users, repositories, favorites, and trending projects — all in one place.

✨ Features
🏠 Home

Search any GitHub username

Beautiful profile card with:

Avatar

Repositories count

Followers / Following

Quick-access tiles: Repos, Timeline, Friends

📂 Repos

Search and browse user repositories

Clean repo list UI

⭐ Favorites

Save and view your favorite GitHub profiles

🔥 Trending

Explore trending GitHub repositories of the day

🛠️ Getting Started
git clone https://github.com/Shebin-shaji/gitspot.git
git clone 
flutter pub get
flutter run

📦 Tech Stack

Flutter

Dart

GitHub REST API

📌 About

GitSpot is designed with a smooth UI, feature-based architecture, and a focus on fast GitHub exploration.
